# SuperIdea downloads

A hobby desktop workspace for CLI coding agents and their Git worktrees, shared
with coworkers who want to try the same way of working.

Download a `SuperIdea-...` archive from [Releases](https://github.com/matsE94/SuperIdea-releases/releases), extract the whole archive, and read
`START-HERE.txt`—your coding agent can help with the instructions. Packages cover
Apple Silicon Macs, native Windows x64, and Ubuntu 26.04 x64. See each release's
metadata for tested environments and requirements.

There is no installer or automatic updater. These are unsigned hobby beta builds;
OS approval may be required. Keep using your own Git, shell and agent tools.

Send feedback to the coworker who shared the app or [open an issue](https://github.com/matsE94/SuperIdea-releases/issues). Include the
version, OS and reproduction steps, without credentials, private source or data.

This repository contains release material only. The application source is private.
