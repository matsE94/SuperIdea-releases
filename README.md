# SuperIdea downloads

A hobby desktop workspace for CLI coding agents and their Git worktrees, shared
with coworkers who want to try the same way of working.

Download a version from [Releases](https://github.com/matsE94/SuperIdea-releases/releases), extract the whole archive, and read
`START-HERE.txt`—your coding agent can help with the instructions. Packages cover
Apple Silicon Macs, native Windows x64, and Ubuntu 26.04 x64. See each release's
metadata for tested environments and requirements.

There is no installer or automatic updater. These are unsigned hobby beta builds;
OS approval may be required. Keep using your own Git, shell and agent tools.

Send feedback to the coworker who shared the app or [open an issue](https://github.com/matsE94/SuperIdea-releases/issues). Include the
version, OS and reproduction steps, without credentials, private source or data.

This repository contains release material only. The application source is private.

Personal and workplace use is free under the [binary terms](LICENSE.txt). You may
redistribute unchanged complete packages with their notices and matching platform
`third-party-sources.tar.gz` archives. Keep the matching sources available beside
the binaries at the same download location. Third-party licenses and mandatory-law
rights prevail, including library modification/replacement and own-use debugging.

Help and each package include offline third-party copyright/license notices.
`LIBRARY-REPLACEMENT.txt` and the source archive's `BUILDING.txt` explain rebuilding
and replacing libraries. Cairo's LZO and Linux/Windows TIFF's JBIG codecs are omitted.
The source archives contain third-party components and their build material only.
